# Handwritten Digit Recognition using Random Forest

## 1. Project Description
This project recognizes handwritten digits from 0 to 9 using Machine Learning.

## 2. Algorithm Used
Random Forest Classifier.

## 3. Dataset
Scikit-learn Digits Dataset.
- Total images: 1,797
- Image dimensions: 8 × 8 pixels
- Number of classes: 10

## 4. Technologies Used
- Python
- Google Colab
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 5. Methodology
1. Load the handwritten digits dataset.
2. Split the data into training and testing sets.
3. Train the Random Forest model.
4. Predict handwritten digits.
5. Evaluate the model using accuracy and confusion matrix.

## 6. Results
The model produces:
- Accuracy score
- Classification report
- Confusion matrix
- Actual vs predicted digit images

## 7. Conclusion
The Random Forest algorithm is used to recognize handwritten digits and predict their corresponding numerical values.

## 8. How to Run
Open the Jupyter Notebook in Google Colab and execute all cells sequentially.
